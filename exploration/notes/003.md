## Claim in my own words

There is no zero of ζ(s), or of any Dirichlet L(s, χ), with Re s > 7/8 (the pole of the principal character at s = 1 aside). The same holds for finite-order Hecke L-functions over ℚ(√−3). Separately, Siegel zeros are excluded uniformly: 1 − β ≥ c / log q for an absolute but non-explicit c > 0.

## Prior state of the art

Before this result, no zero-free half-plane Re s > θ with θ < 1 was known. The best results were zero-free *regions* that shrink toward Re s = 1 as |Im s| grows (de la Vallée Poussin, then Vinogradov–Korobov). A fixed half-plane is a qualitatively stronger result. Uniform exclusion of Siegel zeros was also open; Siegel's theorem is ineffective and only gives 1 − β ≫_ε q^{−ε}.

## Lean statement vs. paper claim

- **ζ and Dirichlet (`QuasiRiemannHypothesis`, `DirichletSevenEighths`).** The challenge files import only `Mathlib` and state the result in Mathlib's own `riemannZeta` and `DirichletCharacter.LFunction`. This is about as clean as statement fidelity gets: Mathlib defines both functions on all of ℂ by analytic continuation, so the statement means exactly what it appears to.

  ```lean
  theorem riemannZeta_ne_zero_of_seven_eighths_lt_re
      {s : ℂ} (hs : (7 / 8 : ℝ) < s.re) : riemannZeta s ≠ 0
  ```

  The Dirichlet version holds for every modulus q and every character χ, with the hypothesis `¬ (χ = 1 ∧ s = 1)`.
- **Siegel zeros (`SiegelZeros`).** The statement is `∃ c > 0, ∀ q ≥ 3, ∀ χ primitive, nontrivial, real-valued, ∀ β ∈ (0,1), L(β, χ) = 0 → c ≤ (1 − β) log q`. This is also pure Mathlib, and it matches the doc. As the doc says, it is non-explicit (∃ c).
- **Hecke over ℚ(√−3) (`HeckeSevenEighths`).** The challenge file *defines its own* L-function machinery (`WeakFEPair` products and related constructions) because Mathlib lacks Hecke L-functions. Statement fidelity here depends on reviewing those definitions by hand. Comparator alone does not establish it.
